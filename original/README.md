# Original notebook (2019, Portuguese)

`2019_original_notebook_pt.py` is the unmodified Colab export of the original notebook this
project was rebuilt from — kept as-is for provenance, not run as part of this project. It used
Colab `#@param` form fields and a Bokeh widget API (`bokeh.models.widgets`, `plot_width`/
`plot_height`, string `legend=`) that predates this rebuild by several major Bokeh releases.

See the repository root for the modernized, English, tested version.
